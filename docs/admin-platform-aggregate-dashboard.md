# داشبورد یکپارچه پلتفرم (Admin Executive Dashboard)

## خلاصه
صفحهٔ `/admin` و `/admin/dashboard` نمای اجرایی واحد برای Pet Date است: KPI زنده از پلتفرم، پیوند (HR)، فروش، باشگاه مشتریان و ایمیل؛ به‌همراه گزارش تجمیعی چندنموداری روی دیزاین Pepito تمام‌عرض.

## API
`GET /api/admin/dashboard` (افزایشی):
- فیلدهای قبلی (`stats`, `recent*`) حفظ می‌شوند
- `modules`: platform / hr / sales / crm / mail
- `series`: روندها، قیف فروش، دلایل CRM، دونات بار ماژول‌ها، ترکیب پرداخت
- `links`: deep-link به داشبورد هر ماژول

## رفتار seed
- بدون دادهٔ ماژول → صفر امن
- با seedهای HR/Sales/CRM موجود → نمودارها و کارت‌های غیرصفر

## غیرریگرسیون
هیچ wipe روی دیتابیس انجام نمی‌شود؛ فقط خواندن زنده از DB.
