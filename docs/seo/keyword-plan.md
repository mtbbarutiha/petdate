# برنامه کلمات کلیدی پت‌دیت (فارسی)

هدف: جذب ترافیک تجاری برای **همبازی پت**، **پت‌شاپ**، **پذیرش** و **مشاوره دامپزشک آنلاین** در ایران — بدون ادعای کلینیک/بیمارستان.

## خوشه‌های اصلی (pillars)

| خوشه | هدف صفحه | نمونه URL |
|------|----------|-----------|
| همبازی / دوستیابی پت | لندینگ + CTA ورود | `/` |
| پت‌شاپ آنلاین | شاپ + دسته‌ها | `/shop`, `/shop/c/*` |
| دامپزشک آنلاین | مشاوره | `/vet-consult` |
| پذیرش حیوان | کارت‌ها + جزئیات | `/adoption`, `/adoption/:slug` |
| پشتیبانی / اعتماد | FAQ | `/faq` |

## کلمات دم‌بلند پیشنهادی (اولویت بالا)

### همبازی پت
- همبازی برای سگ در تهران / ایران
- پیدا کردن همبازی برای پت
- دوستیابی سگ و گربه
- پارتنر پیاده‌روی سگ
- اپ همبازی حیوانات خانگی
- ربات تلگرام همبازی پت

### پت‌شاپ
- خرید غذای سگ آنلاین
- خرید غذای گربه ارزان
- خاک گربه آنلاین
- اسباب بازی گربه خرید
- قلاده سگ خرید اینترنتی
- پت شاپ آنلاین ایران

### دامپزشک
- مشاوره دامپزشک آنلاین
- دامپزشک آنلاین تلگرام
- چت با دامپزشک
- ویزیت آنلاین دامپزشک (بدون ادعای کلینیک)
- سوال از دامپزشک درباره سگ/گربه

### پذیرش
- پذیرش سگ و گربه
- حیوان خانگی برای پذیرش
- به سرپرستی گرفتن گربه
- واگذاری مسئولانه پت

### برند / ناوبری
- پت‌دیت / PetDate / petdate.ir
- ربات پت دیت تلگرام

## نقشه محتوا به صفحه (on-page)

| کلمه / خوشه | Title / H1 | لینک داخلی |
|-------------|------------|------------|
| همبازی پت | عنوان پیش‌فرض لندینگ | فوتر + CTA همبازی |
| پت‌شاپ آنلاین | پت‌شاپ آنلاین — غذا و لوازم پت | ناو + فوتر + محصولات ویژه |
| دامپزشک آنلاین | مشاوره دامپزشک آنلاین | هیرو اسلاید ۱ + ناو |
| سؤالات متداول | FAQ | فوتر + بخش FAQ لندینگ |
| دسته‌های شاپ | `{دسته} | خرید آنلاین` | شبکه دسته‌بندی شاپ |
| پذیرش نام پت | پذیرش {نام} | کارت‌های پذیرش |

## رقبا / تم‌های جستجو (الهام، نه کپی)

تم‌های رایج بازار ایران: فروشگاه‌های پت، گروه‌های تلگرامی همبازی سگ، صفحات مشاوره دامپزشک، آگهی پذیرش. تمایز پت‌دیت: **یک حساب وب+ربات** برای همبازی + شاپ + دامپزشک.

## گام‌های بعدی (غیرکد)

1. ثبت ملک در Google Search Console و ارسال `sitemap.xml` (جزئیات: `search-console.md`).
2. ۳ تا ۵ مقاله کوتاه فارسی روی خوشه‌های دم‌بلند با لینک به `/shop` و `/vet-consult`.
3. دامنه canonical: `https://petdate.ir` — origin روی HTTPS، `www` را به apex ۳۰۱ می‌کند؛ در پنل CDN هم همین host-redirect را بگذارید.
4. پس از ایندکس، ردیابی impressions برای خوشه‌های بالا و تقویت صفحات ضعیف.
